# 🚀 Telegram Forwarder Pro (AI Powered)

A high-performance Windows desktop automation tool designed for Telegram channel administrators and content curators. Intercept, rewrite with Google Gemini AI, sanitize, and forward posts in real time with zero latency.

---

## 🌟 Key Features

- ⚡ **Zero-Latency Client-Side Forwarding:** Connects directly via Telethon user client to capture posts instantly from public, private, and restricted channels.
- 🤖 **Google Gemini AI Integration:** Automatically rewrites incoming content to fit your custom channel tone, summarize long posts, or translate into multiple languages.
- 🛡️ **Watermark & Link Sanitization:** Automatically removes competitor usernames (`@mentions`), external links, hashtags, and promotional footers.
- 🎛️ **Interactive Approval Bot:** Review, edit, or reject rewritten posts directly via an interactive Telegram inline keyboard bot before publishing.
- 🔒 **100% Privacy & Local Storage:** Runs entirely on your local machine. API keys, bot tokens, and session credentials never leave your PC.
- 🖥️ **Modern Desktop UI:** Clean, modern CustomTkinter interface with real-time logs and intuitive setup wizard.

## 🚀 Quick Setup Guide

1. **Download:** Get the installer from Gumroad or request a trial.
2. **Launch:** Run `setup.exe` on your Windows PC.
3. **Authenticate:** Enter your Telegram API ID & API Hash (from `my.telegram.org`).
4. **Configure:** Add your target channels, Gemini API key, and prompt template.
5. **Start:** Click **Start Forwarder** to automate your channels 24/7!
